## 1. 软件概述

### 1.1 软件名称
合成方块记 V1.0

### 1.2 软件用途
本软件是一款基于微信小游戏平台的休闲益智类合成游戏。玩家通过点击投放按钮在 6×6 格子中放置方块，相邻相同等级的方块自动合并为更高级方块，考验玩家的空间规划与策略思维。软件通过激励视频广告实现盈利（IAA 模式）。

### 1.3 运行环境

| 项目 | 要求 |
|------|------|
| 运行平台 | 微信客户端 8.0+ |
| 操作系统 | iOS 12+ / Android 7+ |
| 开发引擎 | Cocos Creator 3.8 |
| 开发语言 | TypeScript |
| 网络 | 需要网络（加载广告） |

### 1.4 面向用户
全年龄段休闲游戏玩家，尤其适合利用碎片时间放松的用户。

## 3. 操作说明

### 3.1 启动游戏

1. 打开微信，搜索或扫描小游戏二维码
2. 进入「合成方块记」游戏主界面
3. 系统自动加载，显示 6×6 空格子、分数栏和操作按钮

【截图 1：游戏主界面】

### 3.2 投放方块

1. 点击屏幕下方 **「投放」** 按钮
2. 系统在随机空位生成一个 1 级方块（蓝色碎块）
3. 若上下左右存在相同等级方块，自动触发合并
4. 合并后方块等级 +1，颜色变化，获得对应分数

【截图 2：投放方块】
【截图 3：方块合并效果】

### 3.3 连锁合并

1. 一次合并后，若新方块与相邻方块等级相同，继续自动合并
2. 连锁合并获得累计分数
3. 最高可合成至 10 级「皇冠」方块

【截图 4：连锁合并】

### 3.4 游戏结束

1. 当 6×6 格子全部占满，无法继续投放时，游戏结束
2. 弹出结束面板，显示本局分数和历史最高分
3. 提供两个选项：
   - **看广告复活**：观看激励视频，清除 3 个最低级方块，继续游戏（每局限 1 次）
   - **重新开始**：清空棋盘，开始新一局

【截图 5：游戏结束面板】
【截图 6：广告复活】

### 3.5 分数规则

| 合并结果等级 | 获得分数 |
|-------------|---------|
| 2 级 | 20 分 |
| 3 级 | 30 分 |
| 4 级 | 40 分 |
| ... | ... |
| 10 级 | 100 分 |

历史最高分自动保存在本地，下次打开仍可查看。

## 5. 技术实现简介

- 采用 Cocos Creator 3.8 游戏引擎开发
- 使用 TypeScript 编写游戏逻辑
- 核心算法 `GridModel` 管理棋盘状态与合并判定
- `GameState` 管理分数、回合和游戏阶段
- 通过微信小游戏 SDK 接入激励视频广告
- 使用 `wx.setStorageSync` 本地存储最高分

## 6. 常见问题

**Q: 格子满了怎么办？**
A: 游戏结束。可观看广告复活一次，或重新开始。

**Q: 方块最高多少级？**
A: 最高 10 级「皇冠」。

**Q: 分数会丢失吗？**
A: 当前局分数在结束后清零；历史最高分永久保存在本地。
