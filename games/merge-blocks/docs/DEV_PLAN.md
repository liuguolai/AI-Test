# 合成方块记 — 7 天开发计划

**目标**：Cocos 项目跑起来，合成逻辑可运行

- [ ] 安装 Cocos Creator 3.8 + 微信开发者工具

- [ ] 新建 Cocos 2D 项目，导入 `assets/scripts/`
- [ ] 运行 `npm test` 确认核心逻辑通过

## Day 5：合规准备

**目标**：并行启动软著和备案

- [ ] 确定游戏名称：**合成方块记**
- [ ] 在 [中国版权保护中心](https://www.ccopyright.com.cn) 申请软著

  - 操作说明：用 `docs/SOFT_COPYRIGHT.md`
- [ ] 微信后台：设置游戏名称、类目、适龄提示
- [ ] 准备自审自查报告

**产出**：软著申请已提交（等 2～3 个月）

## Day 7：提审 + 规划第二款

**目标**：第一款提交审核，第二款开始规划

- [ ] 版本审核提交

- [ ] 审核通过后发布

**产出**：第一款上线 or 审核中

## 软著等待期（2～3 个月）做什么？

不要闲着，利用这段时间：

1. **继续开发第 2、3 款游戏**（同样先申软著）
2. **优化第一款**（加音效、皮肤、分享）
3. **准备抖音小游戏版本**（Cocos 一键构建）
4. **写 AI 公众号文章**推广你的游戏（和之前的 AI 简报结合）
