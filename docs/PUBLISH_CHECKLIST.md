# 微信小游戏上线 Checklist

每款游戏上线前逐项确认。

## 账号与合规

- [ ] 微信公众平台注册小游戏账号
- [ ] 微信认证（个人 ¥30/年）
- [ ] 软著申请提交（名称与游戏一致，如 `合成方块记V1.0`）
- [ ] 小程序备案完成
- [ ] 小游戏备案完成
- [ ] 资质审核 → **情况二：不需要虚拟支付**（纯 IAA）
- [ ] 适龄提示设置
- [ ] 自审自查报告

## 开发与构建

- [ ] `npm test` 通过
- [ ] Cocos Creator 场景节点配置完成
- [ ] `GameAds.ts` 填入真实广告位 ID
- [ ] 微信开发者工具真机测试
- [ ] 激励视频广告播放 / 回调正常

## 提审

- [ ] 游戏名称与软著一致
- [ ] 版本审核材料齐全
- [ ] 无违规内容（赌博、色情、政治敏感）
- [ ] 提交版本审核

## 发布后

- [ ] 开通流量主（需 1000 UV）
- [ ] 监控：留存、eCPM、人均广告次数
- [ ] 记录数据，决定是否加大买量或做第二款

## 每款游戏独立项

| 项目 | 是否每款独立 |
|------|-------------|
| 微信 AppID | ✅ |
| 软著 | ✅ |
| 小游戏备案 | ✅ |
| 广告位 ID | ✅ |
| 公共代码 `packages/shared` | ❌ 共用 |
